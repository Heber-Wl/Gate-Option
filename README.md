## 💹 Sobre o Gate Option

O **Gate Option** é um projeto acadêmico desenvolvido em **Laravel (PHP)** que simula uma **plataforma de investimentos em empresas nacionais**.  
O sistema permite que os usuários realizem **depósitos virtuais**, **comprem e vendam ações**, e acompanhem **em tempo real o desempenho de seus investimentos**.  
Com **gráficos interativos** e **dashboards dinâmicos**, o Gate Option oferece uma experiência prática e educativa sobre o funcionamento do mercado financeiro, facilitando a análise de dados e o controle da rentabilidade dos investimentos.

---

## 🚀 Funcionalidades Principais

- 🧾 Cadastro e autenticação de usuários  
- 💰 Depósitos virtuais e controle de saldo  
- 📈 Simulação de compra e venda de ações  
- 📊 Gráficos interativos com **Chart.js**  
- 🧮 Dashboard com estatísticas em tempo real  
- 🧠 Simulação de empresas e variações de mercado  
- 📜 Histórico de transações e relatórios financeiros  

---

## 🧠 Tecnologias Utilizadas

- **Back-end:** PHP (Laravel)  
- **Front-end:** Blade, JavaScript, Chart.js, DataTables  
- **Banco de Dados:** MySQL  
- **Outros recursos:** Autenticação Laravel, atualização dinâmica de dados e layout responsivo
